== Synopsis

aerospace promote [-h|--help] [--workspace <workspace>]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

The master is the window that occupies the placeholder slot `1` of the
workspace layout skeleton (`[workspace-layout]`). Workspaces without a layout
skeleton treat the first window in the visual order as the master. Example of a
dwm-like master-stack skeleton:

[source,toml]
----
[workspace-layout]
i = '''
h_tiles
  1 @0.55
  v_tiles
    others
'''
----

The command swaps the focused window with the current master. The promoted
window keeps the master slot until the set of windows changes, because the
skeleton is rebuilt from the visual order of the windows.
