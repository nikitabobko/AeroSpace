%{window-id}:: Number. Window unique ID
%{window-id-native}:: Number. macOS native window ID (`CGWindowID`). Useful for integration with other tools that operate on native window IDs.
macOS native tabs are separate windows under the hood. AeroSpace treats the whole tab group as a single window with a stable `%{window-id}`, but `%{window-id-native}` changes whenever another tab is brought to the front.
Different apps implement tabs differently. Apps that use native tabs: Finder.app, Terminal.app. Apps that don't use native tabs: Safari. Third-party apps usually don't use native tabs
%{window-title}:: String. Window title
%{window-is-fullscreen}:: Boolean. Is window in fullscreen by `aerospace fullscreen` command
%{window-is-sticky}:: Boolean. Is window in sticky mode by `aerospace sticky` command
%{window-layout}:: String. An alias for `%{window-parent-container-layout}`
%{window-parent-container-layout}:: String. The layout (`v_tiles`, `h_tiles`, `v_accordion`, `h_accordion`, `floating`) of the window's parent container.
